# Overview

Looking for a guided walkthrough instead? Try the [ScaleFM Demo](https://colab.research.google.com/github/automl/scalefm/blob/master/tutorials/scalefm_demo.ipynb) in Google Colab.

1. **Basic usage examples** demonstrate fundamental usage.
Learn how to perform Hyperparameter Optimization (HPO) and analyze runs on a basic level.

2. **Convenience examples** show tensorboard compatibility and its integration, SLURM-scripting and understand file management within the evaluate pipeline function used in ScaleFM.

3. **Efficiency examples** show how to parallelize the evaluations, e.g. with PyTorch DDP and FSDP, natively or with PyTorch Lightning.

4. **Experimental examples** tailored for ScaleFM contributors. These examples provide insights and practices for experimental scenarios.

5. **Real-world examples** demonstrate how to apply ScaleFM to real-world problems, such as scaling studies.
